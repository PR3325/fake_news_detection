# 📰 Fake News Detection

A Machine Learning and Natural Language Processing (NLP) based project that detects whether a given news article is **Real or Fake**.

## 📌 About the Project

Fake News Detection analyzes the textual content of news articles and classifies them as either **Fake News** or **Real News**. The project uses text preprocessing techniques and **TF-IDF (Term Frequency-Inverse Document Frequency)** to convert news text into numerical features. A **Logistic Regression** model is then trained to perform the classification.

The project also includes a **Streamlit web interface**, allowing users to enter news content and get predictions through an easy-to-use interface.

## 🚀 Features

* Detects whether news is Real or Fake
* Text preprocessing using NLP techniques
* TF-IDF feature extraction
* Logistic Regression classification
* Interactive Streamlit web interface
* Real-time prediction

## 🛠️ Technologies Used

* **Pandas**

* **Logistic Regression**
* **Streamlit**

## 🔄 Workflow

```text
News Article
     ↓
Text Preprocessing
     ↓
TF-IDF Vectorization
     ↓
Machine Learning Model
     ↓
Logistic Regression
     ↓
Real / Fake Prediction
```

## 🎯 Objective

The main objective of this project is to demonstrate how **NLP and Machine Learning** can be used to automatically identify potentially misleading or fake news based on its textual content.

## ⚠️ Disclaimer

This project is developed for **educational and demonstration purposes**. The prediction should not be considered a definitive verification of whether a news article is factually true.
